## Troubleshooting

### **"Still getting upload errors"**
- Try Method B (copy-paste) instead of import
- Ensure you're using the _GOOGLE_DOCS_READY version
- Check browser cache (Ctrl+Shift+Del)

### **"Text looks corrupted (€ shows as ?)"**
- Google Doc needs to be in UTF-8 encoding
- File → Settings → Encoding should be UTF-8
- Usually happens on older Google Drive imports

### **"Images aren't embedding properly"**
- Don't paste images into the markdown
- Upload document first, add images manually after
- Use Insert → Image for best results

### **"Tables look wrong"**
- Google Docs automatically reformats markdown tables
- May need minor manual adjustment
- All data is preserved, just formatting may shift
